# Public Library Projection

The site is a generated or generation-source projection of `registry/` and `receipts/`.

Minimum route families supported by generation contract:

- `/authors/<AuthorID>`
- `/objects/<ObjectID>`
- `/sources/<SourceID>`
- `/relations/<RelationID>`
- `/domains/<slug>`
- `/focus/<slug>`
- `/questions/<slug>`
- `/evidence/<slug>`
- `/maturity/<slug>`
- `/timeline/`

The registry remains the source of truth.
